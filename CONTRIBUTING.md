# Contribuir

1. Crea una rama desde `main`.
2. Instala con `pnpm install`.
3. Mantén TypeScript estricto y evita nuevas dependencias sin justificar licencia/mantenimiento.
4. Ejecuta `pnpm check` y `pnpm test:e2e`.
5. Documenta cualquier cambio de modelo, revisión, origen de red, privacidad o compatibilidad.

Los fixtures deben ser generados o tener licencia explícita. Nunca añadas películas, audio privado, tokens ni datos personales.
